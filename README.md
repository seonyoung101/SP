# 섬망 SP 시뮬레이션 (WebXR)

「섬망 환자 조기발견 및 Nu-DESC 기반 간호중재·SBAR 보고 SP 시나리오」를 WebXR(three.js)로 옮긴 프로젝트입니다.
학습자가 신규간호사가 되어 새벽 2시 병실에서 환자(김두두, 80세)를 만나 **안전 확보 → 섬망 선별 → 비약물적 중재 → SBAR 보고**를 10분 안에 수행합니다.

- 빌드 도구 없음(정적 파일). three.js는 `vendor/`에 포함되어 있어 외부 CDN 없이 동작합니다.
- VR(Meta Quest 브라우저 등)과 PC 브라우저(마우스)를 모두 지원합니다.

## 실행

**GitHub Pages로 열기** (WebXR은 HTTPS가 필요합니다)

1. 저장소 → Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)` → Save
2. 1~2분 뒤 `https://seonyoung101.github.io/SP/` 접속
3. Quest 브라우저에서 같은 주소를 열고 **ENTER VR** 버튼을 누릅니다.

**로컬에서 열기**: 저장소 폴더에서 `python3 -m http.server 8000` → `http://localhost:8000` (localhost는 HTTPS 없이도 WebXR 가능)

URL 파라미터: `?practice=1` 연습 모드(시간 제한 없음) · `?debug=1` 정서 강도 표시 · `?hallu=0` 환시(벌레) 연출 끔

## 조작

| 환경 | 조작 |
| --- | --- |
| VR | 컨트롤러(또는 손) 레이로 버튼을 가리키고 트리거 |
| PC | 마우스 클릭, 드래그로 둘러보기 |

- 왼쪽 패널: 간호 수행 메뉴(안전 / 사정 / 중재 / 보고 탭)
- 오른쪽 패널: 남은 시간, 단계, 수행 결과 카드(활력징후·사정 결과·처방 등)
- 벽면 패널: 대화·수행 기록(환자 대사는 브라우저 음성합성으로 읽어 줍니다)
- Nu-DESC 채점, SBAR 보고, read-back은 가운데 폼에서 진행합니다.

## 시나리오 구성

대본의 4단계(0~3 / 3~7 / 7~9 / 9~10분)와 20개 간호 수행을 그대로 따릅니다.

- **환자 반응**: 대본의 대사를 수행에 연결했습니다. 정서 강도 7 → 3~4 → 3은 Foley 꺾임 해소·지남력 재안내·감정 인정·소변 배출 설명으로 내려갑니다.
- **종료 조건**: 비약물적 중재 3가지 이상 + 신체보호대 미사용 + 재평가 → “그래.. 좀 누워있을 게.” / 미흡하면 “집에 갈 거야!”(침대 끝에 앉음)
- **타이머**: 러닝 10분, 종료 3분 전(7분) 알림음·배너. 9분 경과 시 “근데 여기가 어디라고 했지?” 1회(지남력 재안내를 했을 때).
- **자동 채점 초안**: 교수자 체크리스트 14항목(28점, 항목별 2/1/0)을 로그로 판정해 종료 후 보여 줍니다. 최종 평가는 교수자 체크리스트로 확인하세요.

## 교수자 확인이 필요한 부분 (원 대본에 없어 임시로 넣은 값)

`js/scenario-data.js`, `js/scenario.js`에서 수정할 수 있습니다.

1. **당직의 구두 처방** — 대본에 처방 내용이 없어 `아세트아미노펜 650mg 경구 1회, 1시간 뒤 체온 재측정`으로 임시 설정했습니다(`ORDER`, `READBACK`).
2. **오답 경로 대사** — 신체보호대 적용(“이거 풀어! 묶지 마!”), 환시 반박(“있잖아! 저기!”) 대사는 대본에 없습니다.
3. **SBAR 문항·정답 기준** — 요소마다 정답 2개 이상 + 오답 0개일 때 충족으로 봅니다(`SBAR`, `SBAR_NEED_CORRECT`).
4. **Nu-DESC 판정** — 총점 2점 이상이 양성입니다. 4번 항목 만점은 지남력·의사소통·착각/환각을 각각 1점 이상 채점한 경우입니다.
5. **“10분 시점” 대사** — 9분 경과 시점으로 해석했습니다(`META.idleLineAtSec`).
6. 정서 강도 증감폭(수행별 −0.5~−2, 오답 +1.5~+2)은 연출용 값입니다.

## 환자·침대 모델

외부 3D 파일 없이 코드로 만든 모델입니다(환자복 무늬, 얼굴·손, 등받이가 올라가는 병원 침대, 난간, 이불 주름, 수액 폴대와 펌프 표시창, 눈금이 있는 소변주머니).
상황에 따라 바뀝니다: 출혈→거즈/필름, 수액 펌프 `40 mL/h`→`STOPPED`, Foley 꺾임→소변 배출(주머니 수위 상승), 침대 높이·난간, 환자 자세(반좌위 → 누움 / 침대 끝에 앉음).
더 사실적인 인체 모델이 필요하면 glTF(.glb)를 구해 `js/patient.js`의 환자 부분을 교체하세요.

## 내가 만든 방으로 바꾸기

`js/room.js`의 `buildRoom()`은 임시 병실입니다. 직접 만든 방(glTF 등)으로 바꾸려면 같은 형태의 객체를 돌려주면 됩니다.

```js
// { group, setLight(on), setClock('02:03'), update(dt) }
```

좌표 규칙: 간호사 시작 위치 `(0, 0, 0.9)`에서 `-z` 방향을 보고, 침대는 `(0, 0, -1.3)`에 머리를 `-z` 쪽 벽으로 둡니다. 환자의 오른쪽은 `-x`입니다.

## 파일 구조

```
index.html            진입 페이지
js/scenario-data.js   대본·학습목표·메뉴·SBAR 문항 (데이터)
js/scenario.js        시나리오 엔진·채점 (three.js 무관, node로 테스트 가능)
js/main.js            WebXR 진입점, 입력(마우스/컨트롤러), 루프
js/panels.js          패널 4종(메뉴/상황 정보/자막/폼)
js/ui.js              캔버스 → 3D 패널 공통 코드
js/patient.js         병원 침대(등받이·난간)·환자·수액 폴대/펌프·Foley/소변주머니·환시 연출
js/room.js            임시 병실
tests/scenario.test.mjs  엔진 테스트 (node tests/scenario.test.mjs)
vendor/three/         three.js r160, VRButton, RoundedBoxGeometry
```
